# Rishi & Vishnupriya Wedding Invitation

Modern premium wedding invitation.

### Design
- Full-page decorative background
- Bold, larger typography
- No cursive fonts
- Wine / antique-gold / ivory palette
- Glass-style premium sections
- Responsive mobile layout
- Countdown
- Photo slideshow
- Opening animation
- Falling petals
- Background music with generated fallback

### Main files
- `index.html`
- `styles.css`
- `script.js`
- `assets/background.svg`

### Personal assets
Put these files in the indicated folders:
- `assets/photos/img-1.jpeg`
- `assets/photos/img-2.jpeg`
- `assets/photos/img-3.jpeg`
- `assets/music/background-music.mpeg`
- `assets/directions/venue-map.jpg`

Open `index.html` directly or use VS Code Live Server.
